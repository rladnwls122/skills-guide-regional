> 문서 유형: reference

축별로 **어느 문서의 어느 절을 읽어야 하는지**를 적었다. 문서 전체를 읽으라는 뜻이 아니다 — 대회 준비에 필요한 절만 골랐다.

읽는 기준 하나 — **"왜 그렇게 동작하는지"가 궁금하면 문서를 읽고, "인자가 뭐였지"가 궁금하면 `aws <service> <command> help` 를 친다.**

## 7. CLI 참조

문서보다 빠른 경우가 많다.

```bash
aws ec2 describe-vpcs help              # 인자와 필터 목록
aws ec2 wait vpc-available help         # wait 하위 명령 목록
aws configure set region ap-northeast-2
```

`--query` 는 JMESPath 다. 채점 스크립트가 전부 이걸로 쓰여 있으니 읽을 줄 알아야 한다.

- [JMESPath 튜토리얼](https://jmespath.org/tutorial.html) — 필터 표현식 `[?Key=='Name']` 절까지만
- [AWS CLI 출력 필터링](https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-filter.html)

자주 쓰는 형태:

```bash
--query "Vpcs[].CidrBlock"                       # 리스트에서 필드 뽑기
--query "Subnets[0].CidrBlock"                   # 첫 번째만
--query "Tags[?Key=='Name'].Value"               # 조건 필터
--query "Entries[?(!(Egress) && RuleAction=='allow')].CidrBlock"   # 부정 + AND
--output text                                    # 따옴표 없는 평문
```
