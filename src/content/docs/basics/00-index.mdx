> 문서 유형: 개요

[skills-guide](https://skills-learn.zenru.net/)(전국판)의 선수 학습을 **지방대회 기출에 맞춰 다시 짰다.** 전국판이 18편으로 개념을 넓게 깐다면 이쪽은 4년치 기출에 실제로 나온 것만 남기고, 지방에만 나온 것(EFS·Athena)을 새로 넣었다.

각 문서는 **앞 문서를 전제하지 않는다.** 필요한 것만 골라 봐도 된다.

## 전국판에서 무엇을 바꿨나

| 처리 | 문서 | 이유 |
| --- | --- | --- |
| 새로 씀 | [EFS](/basics/12-efs/), [Athena·Glue](/basics/13-athena-glue/) | 2026 2과제 ①②. 전국판에 없다 |
| 지방 기출 예제로 교체 | VPC · IAM · ALB · DynamoDB · KMS | 예제가 전국 과제(set-02 등) 기준이었다 |
| 범위를 줄임 | K8s·EKS | 지방은 클러스터를 띄우고 Deployment 를 올리는 선까지다 |
| 새로 씀 | [셸과 AWS CLI](/basics/01-shell-awscli/) | 채점이 CLI 출력 대조라 **JMESPath 를 읽는 것 자체가 실력**이다 |
| 뺌 | Go 앱, EventBridge, Step Functions, WAF, CloudFront 심화 | 4년간 지방 기출에 없거나 한 번뿐이다 |
