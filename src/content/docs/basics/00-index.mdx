> 문서 유형: 개요

[skills-guide](https://skills-2026-learn-module.vercel.app/)(전국판)의 선수 학습을 **지방대회 기출에 맞춰 다시 구성했다.** 전국판이 18편에 걸쳐 AWS 개념을 폭넓게 다룬다면, 이쪽은 2023~2026년 지방대회에 실제로 등장한 내용에 집중한다. 지방대회에서 새롭게 확인된 EFS와 Athena·Glue도 별도로 추가했다.

각 문서는 **앞의 내용을 몰라도 볼 수 있도록 구성했다.** 이미 알고 있는 내용은 건너뛰고, 부족한 부분만 골라서 공부하면 된다.
