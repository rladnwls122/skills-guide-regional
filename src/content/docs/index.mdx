[skills-guide](https://skills-2026-learn-module.vercel.app/)(전국대회판)의 지방대회 버전이다. 전국판이 개념을 순서대로 쌓아가는 교재라면, 이 책은 **2023~2026년 지방대회 기출을 중심으로 실제 출제 내용을 익히고 반복해서 연습하는 것**에 초점을 맞췄다.

지방대회는 4시간 동안 2과제를 수행한다. 한 과제에서 여러 AWS 서비스를 다루지만, 각 서비스의 설정은 전국대회보다 비교적 단순한 편이다. 따라서 이 교재에서는 하나의 기술을 깊게 파기보다 **기출에서 반복해서 등장하는 구성을 익히고, 제한 시간 안에 요구사항을 빠짐없이 구현하는 연습**에 집중한다.

AWS가 처음인 사람도 따라올 수 있도록 기본 개념부터 설명한다. 서버와 네트워크가 익숙하지 않다면 [사전 지식](/basics/00-index/)부터 시작하고, 이미 AWS를 사용해 본 적이 있다면 필요한 부분만 골라서 공부해도 된다.

## 학습 순서

<Steps>

1. **기초 개념 익히기**

   AWS CLI, VPC, IAM 등 뒤의 내용을 이해하는 데 필요한 기본 개념을 먼저 익힌다.

2. **대회와 채점 방식 이해하기**

   실제 과제의 구성과 채점 기준을 살펴보면서 무엇을 정확하게 구현해야 하는지 알아본다.

3. **반복 출제 영역 연습하기**

   네트워크, Bastion, IAM, 애플리케이션 배포, 데이터 저장소, 관측 등 기출에서 반복해서 등장한 영역을 하나씩 연습한다.

4. **2과제 유형 익히기**

   2023~2026년 2과제를 유형별로 살펴보고, 새로운 과제가 나와도 대응할 수 있도록 연습한다.

5. **실전 훈련하기**

   제한 시간 안에 과제를 처음부터 끝까지 수행하고, 마지막에는 체크리스트를 이용해 누락된 항목을 확인한다.

</Steps>

## 이 교재의 근거

본문의 수치와 명령어, 리소스 이름은 실제로 시행된 과제지·채점기준·채점 스크립트를 바탕으로 정리했다.

| 연도 | 자료 | 1과제 | 2과제 |
| --- | --- | --- | --- |
| 2023 | 과제지 PDF, 1과제 채점기준(답지) | Web Service Provisioning | Automation (ETL) |
| 2024 | 과제지·채점기준표·mark.sh·배포파일 | Web Service Provisioning | Automation (CI/CD) |
| 2025 | 과제지·채점기준·배포파일 | Solution Architecture | Small Challenge ×4 |
| 2026 | 과제지·채점기준·mark.sh·배포파일 | Solution Architecture | Small Challenge ×4 |

자료만으로 직접 확인하기 어려운 내용은 **"추정"**으로 표시했다. 확인된 내용과 해석을 구분해서 정리한다.
