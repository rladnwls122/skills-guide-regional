문체·용어 규칙의 원본은 skills-guide(전국판)의 `src/content/docs/reference/style.mdx` 다. 크게 고치기 전에 그 문서를 확인한다.

**목적이 규칙보다 위다.** 산출물은 읽는 사람의 이해와 역량이지 완결된 참고서가 아니다. 규칙끼리 판단이 갈리면 이쪽으로 정한다.

## 이 저장소의 문서 유형

frontmatter 다음 본문 첫 줄에 `> 문서 유형: ...` 을 둔다. 값은 `explanation` · `tutorial` · `how-to` · `reference` · `개요` 다섯 중 하나다. 한 문서에 두 유형을 섞지 않는다.

| 문서 | 유형 |
| --- | --- |
| `00-competition-map` | 개요 |
| `01-past-exams`, `11-links` | reference |
| `02-scoring`, `03`~`07` 축 문서 | explanation |
| `08-task2-catalog` | reference |
| `09-drills`, `10-checklist` | how-to |

## 깊이의 경계

문서에는 *왜 그렇게 동작하는지* 를 쓰고, 인자 목록·전체 스펙·버전별 차이는 공식 문서로 링크한다. 기준은 하나 — 그 문단을 지웠을 때 독자가 "왜"를 잃으면 남기고 "무엇을"만 잃으면 링크로 바꾼다. 옮겨 적은 문단은 원문이 바뀌면 틀린 값이 된다.

각 축 문서 끝의 "참고 문서" 절과 `11-links` 는 **어느 문서의 어느 절을 읽으라**까지 적는다. 링크만 나열하지 않는다.

## 근거를 섞지 않는다

- 과제지·채점기준·채점 스크립트에서 온 값은 그대로 쓴다. 인용할 때 몇 년 몇 과제 몇 번 항목인지 적는다.
- 추정은 추정이라고 적는다(`01-past-exams` 6절이 그 형태다).
- 채점기준 자체의 오류를 발견하면 지우지 말고 `02-scoring` 7절 표에 추가한다. 대회장에서 당황하지 않는 것이 목적이다.

## 문법과 링크

- Starlight 가 frontmatter 의 `title` 을 제목으로 렌더한다. 본문에 H1 을 따로 쓰지 않는다.
- **사이트 내부 링크는 절대 경로**(`/exam/02-scoring/`). 상대 링크는 `starlight-links-validator` 가 검사하지 않는다.
- **`.md` 로 쓴다.** 본문에 `<선수 비번호>`·`{"name": "..."}` 같은 꺾쇠와 중괄호가 그대로 나오므로 `.mdx` 면 JSX 로 파싱돼 빌드가 깨진다. 컴포넌트를 쓰는 랜딩만 예외다.
- 홑물결(`~`) 취소선은 꺼져 있다. `3~4h` 같은 범위 표기가 문단 안에서 짝 지어지던 것을 막았다. 겹물결(`~~`)만 취소선이다.
- 사이드바 순서는 frontmatter 의 `sidebar.order` 다. 문서를 새로 넣으면 뒤 문서들의 번호까지 함께 민다.

## 표

- 표 셀에 문장급 정보를 넣지 않는다. 대조표는 값과 짧은 구절까지다.
- 연도 대조표에서 **없었던 해는 빈칸이나 `—` 로 두고 "없음"을 남발하지 않는다.**
- 배점표는 실제 채점기준의 숫자를 그대로 옮긴다. 반올림하거나 합치지 않는다.

## 독자는 고1 AWS 초보다

이 저장소의 독자는 **고등학교 1학년, AWS 를 처음 만지는 사람**이다. 전국판보다 한 단계 더 친절하게 쓴다.

- `basics/` 는 문서 첫머리에 `**선수 학습 n/15.** 앞선 문서를 전제하지 않는다. 처음 보는 사람 기준으로 씁니다.` 를 두고, 그다음 `## 이 문서를 왜 읽나` 절로 **왜 배우는지부터** 말한다.
- 새 개념은 **비유를 먼저** 준다(EFS = 교실 공용 폴더, Lambda = 손님 올 때만 여는 가게). 비유가 억지스러우면 안 쓰는 편이 낫다.
- 약어는 첫 등장에서 풀어 쓴다(IA = Infrequent Access, IaC = Infrastructure as Code).
- 겁주지 않는다. "틀리면 0점" 만 적지 말고 **무엇을 보면 되는지**를 함께 준다.
- 조용히 실패하는 지점은 `<Aside type="danger">` 로 눈에 띄게 둔다 — 초보가 가장 오래 헤매는 곳이다.
- 실습에 과금 리소스가 있으면 **정리하라는 말을 실습 안에** 넣는다.

## 초심자 가독성

용어는 정의가 사용보다 먼저 온다(첫 등장에서 한 줄 정의 또는 링크, 약어는 풀어 쓴다). 괄호 안에 핵심 정의를 숨기지 않고, 부정을 두 겹 이상 겹치지 않는다. 채점 서술("채점이 이걸 본다")은 동작 원리 설명을 대체하지 못한다 — 왜 그렇게 되는지를 먼저 쓰고 채점을 덧붙인다.

한 문장이 80자를 넘으면 절이 셋 이상 붙은 것이니 끊는다. 다만 기계적으로 토막 내지 않는다.
