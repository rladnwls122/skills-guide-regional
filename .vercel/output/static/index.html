4시간 × 2과제. 깊이보다 누락 없음.

네 해 기출의 과제지·채점기준·채점 스크립트를 분해했다. 매년 나오는 축을 찾아 반복 훈련한다.
지형도부터 보기AWS 가 처음이라면

skills-guide(전국대회판)의 지방대회 버전이다. 전국판이 “한 달에 걸쳐 개념부터 쌓는다”라면 이 문서는 네 해 기출을 축으로 분해해 반복 출제 지점을 훈련한다에 가깝다.

지방대회는 4시간 × 2과제이고, 과제 하나가 다루는 서비스 수는 많지만 각 항목의 깊이는 전국보다 얕다. 그래서 훈련 전략이 다르다 — 깊이보다 속도와 누락 없음이다.

AWS 를 처음 만지는 사람 기준으로 썼다. 서버·네트워크가 뭔지부터 궁금하면 사전 지식 15편을 먼저 본다. 필요한 것만 골라 봐도 된다.

시간이 없다면

섹션 제목: “시간이 없다면”

  1. AWS 가 처음이면 사전 지식 01·02·03 부터 (반나절)

    셸과 AWS CLI, VPC, IAM 셋만 알면 나머지 문서가 읽힌다.

  2. 채점 해부 를 먼저 읽는다

    채점이 CLI 출력 대조라는 사실 하나에서 이 대회의 감점 규칙 거의 전부가 나온다.

  3. 축 1 — 네트워크 로 간다

    4년 연속 나왔고 2026엔 1과제 배점의 31%다.

  4. 축 2 — Bastion·IAM 을 확인한다

    배점은 작지만 무너지면 나머지 전부가 0이다.
