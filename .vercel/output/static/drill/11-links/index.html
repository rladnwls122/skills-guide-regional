공식 문서 링크 맵

문서 유형: reference

축별로 어느 문서의 어느 절을 읽어야 하는지를 적었다. 문서 전체를 읽으라는 뜻이 아니다 — 대회 준비에 필요한 절만 골랐다.

읽는 기준 하나 — “왜 그렇게 동작하는지”가 궁금하면 문서를 읽고, “인자가 뭐였지”가 궁금하면 aws <service> <command> help 를 친다.

1. 네트워크 → 축 1

섹션 제목: “1. 네트워크 → 축 1”
문서읽을 절왜
VPC 서브넷 구성“Subnet routing”서브넷이 public 이 되는 조건이 라우팅뿐임을 확인
라우팅 테이블“Route priority”가장 구체적인 경로가 이긴다
NAT Gateway“NAT gateway basics”, “Pricing”AZ별 배치 이유
네트워크 ACL“Ephemeral ports”, “Rules”stateless 라 응답 포트를 열어야 하는 이유
보안 그룹“Security group rules”NACL 과의 차이
VPC Peering“Update route tables”Peering 이 길을 만들지 않는다
Peering DNS 옵션전체 (짧다)2026 1-7 항목의 근거
PrivateLink 인터페이스 엔드포인트“Create an interface endpoint”보안 그룹이 필요한 이유
Gateway 엔드포인트첫 절Interface 와 무엇이 다른지
VPC Flow Logs“IAM role for publishing”CLI 로 만들 때 필요한 role

2. Bastion·IAM → 축 2

섹션 제목: “2. Bastion·IAM → 축 2”
문서읽을 절왜
EC2 인스턴스 프로파일전체role 이 인스턴스에 붙는 구조
인스턴스 메타데이터“IMDSv2”자기 인스턴스 ID 를 얻는 법
Session Manager 사전 조건전체SSM 이 안 될 때 볼 네 가지
SSM VPC 엔드포인트“Create endpoints”NAT 없이 SSM
종료 방지전체 (짧다)2025 2과제 ④
IAM 정책 평가 논리“Determining whether a request is allowed or denied”Deny 가 항상 이긴다
IAM 조건 연산자“Multivalued context keys”ForAllValues: 접두사의 의미
CloudShell“Persistent storage”리전별로 별개다

3. 컴퓨팅·로드밸런서 → 축 3

섹션 제목: “3. 컴퓨팅·로드밸런서 → 축 3”
문서읽을 절왜
ALB 리스너 규칙“Rule action types”fixed-response 와 기본 동작
ALB 상태 확인“Health check settings”unhealthy 원인 목록
ALB 지표표 전체ELB_4XX vs Target_4XX
시작 템플릿“Tag specifications”인스턴스 Name 태그가 붙는 자리
ASG 태그“PropagateAtLaunch”태그 전파
ASG 대상 추적“Predefined metrics”CPU 70% 정책
EC2 user data“Run commands at launch”, “Troubleshoot”로그가 /var/log/cloud-init-output.log 에 있다
ECS 작업 정의“logConfiguration”awslogs 드라이버
ECS Service Connect“How it works”프록시 컨테이너가 붙는 구조
ECS Exec“Prerequisites”필요한 IAM 권한
ECR 이미지 스캔“Basic scanning”스캔 결과 형식
ECR 태그 변경 불가전체 (짧다)immutable 켜는 순서
EKS 클러스터 엔드포인트 접근“Private only”2024 Private 클러스터
EKS Fargate 프로파일“Considerations”DaemonSet 이 안 되는 이유
Cluster Autoscaler“Cluster Autoscaler”Pod 가 늘면 Node 도 늘게

4. 데이터 → 축 4

섹션 제목: “4. 데이터 → 축 4”
문서읽을 절왜
Aurora 클러스터 생성“Creating a DB cluster”포트 지정 위치
Aurora 암호화“Limitations”생성 후 못 켠다
DB 서브넷 그룹“DB subnet group”2 AZ 요구
DynamoDB 저장 시 암호화키 종류 비교표AWS 소유 / AWS 관리형 / 고객 관리형
DynamoDB 백업“On-demand backup”PITR 과 별개다
DynamoDB 세분화 액세스 제어“dynamodb:Attributes”2026 2과제 ③ 의 정답
DocumentDB 감사전체파라미터 그룹 + 로그 내보내기 두 곳
ElastiCache 클러스터 모드“Comparison”샤딩이 무엇을 바꾸나
ElastiCache 전송 중 암호화“Conditions”켜면 클라이언트가 TLS 로 붙어야 한다
EFS 자동 마운트“Using fstab”user data 에 넣을 내용
EFS 수명 주기“Transition to IA”AFTER_30_DAYS
EFS 마운트 대상 보안“NFS port 2049”마운트가 멈추는 원인 1위
Glue 분류자“CSV classifier”헤더 처리
Athena CREATE TABLE“TBLPROPERTIES”skip.header.line.count
Athena 워크그룹 제어“Per query data limit”1GB = 1073741824
Secrets Manager 암호화“Permissions for the KMS key”읽는 쪽에 kms:Decrypt 가 필요한 이유
